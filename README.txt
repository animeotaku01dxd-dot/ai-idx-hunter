AI IDX Hunter v0.1 - PWA Prototype

Isi:
- Dashboard scanner dengan data simulasi.
- Filter pencarian dan status momentum.
- Watchlist lokal di perangkat.
- Tombol notifikasi demo.
- PWA manifest dan service worker untuk instalasi/offline dasar.

PENTING:
Data saham adalah data contoh, bukan harga pasar aktual.
Belum terhubung ke Stockbit, BEI, API, broker flow, order book, atau running trade.
Tidak ada transaksi otomatis.

Untuk menjalankan:
1. Upload seluruh isi folder ini ke hosting HTTPS yang mendukung file statis.
2. Buka URL hosting di Chrome Android.
3. Menu Chrome (tiga titik) > Tambahkan ke layar utama / Install app.
4. Izin notifikasi diberikan melalui tombol di dashboard.

Tahap berikutnya:
Integrasi hanya dengan API/sumber data yang resmi dan memiliki izin penggunaan.
